🏛 LOH — Land & Cadastral Registry

Full-stack land records management platform implementing the Professional Authority Model
Vue 3 + Vite FastAPI (Python 3.12) PostgreSQL 15 JWT Auth Docker Compose Role-based Access Control

1. Purpose & Scope

LOH is a web-based land administration system that enforces the Professional Authority Model — a controlled division of labour between surveyors, cadastral officers, lawyers, registrars, banks, courts, municipalities, tax authorities, and citizens.

No single user can unilaterally alter authoritative records. Every action is gated by role, every registration requires a prior approval step, and every substantive change requires documentary evidence or a court order. The system records an immutable audit trail for every title change.

DomainWhat the system manages
Parcel creationSurvey plan submission → cadastral review → official parcel activation
Title registrationApplication → instrument preparation → registrar decision → title record
EncumbrancesMortgages, tax liens, court seizures, municipal restrictions, easements, and releases
CorrectionsThree-level correction workflow: clerical, technical, substantive
QueriesTiered public/restricted search across parcels, titles, and encumbrances

4. Role & Permission Model

Every API action is checked against a central permission table in backend/app/core/permissions.py. No role can exceed its defined boundary.

surveyor
  • Submit survey plans
  • View survey plans and parcels (detail)
  • Submit technical correction requests
cadastral_officer
  • Approve or reject survey plans
  • Create official parcels
  • Submit and approve clerical & technical corrections
lawyer_notary
  • Prepare and submit title instruments
  • Submit private encumbrances (leases, easements)
  • Read full title records for authorized transactions
registrar
  • Examine and decide on title applications
  • Approve and release encumbrances
  • Approve clerical corrections
bank
  • Submit mortgage instruments
  • Release mortgages
tax_authority
  • Submit tax liens
  • Release tax liens
court
  • Submit court seizures and judgment liens
  • Submit substantive correction orders
  • Release court orders
municipality
  • Submit municipal restrictions
  • Submit public rights-of-way
  • Release municipal encumbrances
citizen
  • Initiate title applications
  • Submit adverse claims and private encumbrances
  • Query public records
admin
  • All permissions
  • Create and manage user accounts
  • Assign roles
